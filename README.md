# MetaView - Web3 Video Rewards Platform

A decentralized video streaming platform that rewards users with cryptocurrency for watching content. Built with React, Web3.js, and smart contracts.

## 🌟 Features

- **Video Streaming**: Watch videos with a modern, responsive player
- **Web3 Integration**: Connect your MetaMask wallet to earn rewards
- **Token Rewards**: Earn WRT tokens for watching videos
- **Dark Mode**: Beautiful dark/light theme support
- **Local File Support**: Upload and watch your own videos
- **User Dashboard**: Track your watch time and earned rewards
- **Profile Management**: View your watch history and favorite videos

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- MetaMask wallet
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/krishnabandewar/Metaview.git
cd Metaview/frontend
```

2. Install dependencies:
```bash
npm install
```

3. Create a `.env` file in the frontend directory with the following variables:
```
REACT_APP_REWARD_TOKEN_ADDRESS=your_token_address
REACT_APP_NETWORK_ID=your_network_id
```

4. Start the development server:
```bash
npm start
```

## 💡 How It Works

1. Connect your MetaMask wallet
2. Watch videos for at least 10 seconds
3. Click the "Claim Reward" button to receive WRT tokens
4. Track your earnings in the dashboard

## 🛠️ Tech Stack

- **Frontend**: React.js, Web3.js
- **Smart Contracts**: Solidity, OpenZeppelin
- **Styling**: CSS-in-JS, Material-UI
- **Deployment**: Vercel
